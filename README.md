# Weather wallpaper

current functionality:

### python3 Kolorek.py "#RRGGBB"
    creates and sets  wallpaper with solid color of "#RRGGBB"
### python3 Kolorek.py "#RRGGBB" "RRGGBB"
    creates a wallpaper with a gradient going from left to right with the left color being the first arg

right now it works only on linux w/ gnome desktop environment
